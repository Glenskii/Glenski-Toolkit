# Skill Source Policy

`Glenski-Toolkit/skills/` is the canonical public source for every released skill.

The marketplace repository is a distribution mirror. It must not receive independent instruction, documentation, script, or support-file edits. A marketplace release is rebuilt from the matching Toolkit skill, then validated and submitted from one immutable commit.

## Release rule

1. Author and review the complete skill in this repository.
2. Run its validators, tests, wording checks, and package inventory review.
3. Copy the approved package to the marketplace mirror without reducing its instruction or support material.
4. Compare the mirrored package with the approved source before submission.
5. Submit the exact immutable source URL and retain the production readback.

No public skill may be reduced to satisfy a listing, a display panel, or a packaging shortcut. If a platform needs shorter card copy, create that copy separately and preserve the full skill package.
